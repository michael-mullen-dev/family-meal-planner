# Family Meal Planner

A mobile-friendly web app that lets a whole family plan their meals for the week together. Each person plans their own week, and everything syncs across everyone's devices through a shared family code.

**Live app:** https://f00d4thought.netlify.app



## Features

- **Family accounts:** create a family or join one with a family code, then add members
- **Weekly planner:** pick breakfast, lunch, dinner, snacks, and sides for each day
- **Meal library:** 150+ meals with search, plus the ability to add your own
- **Nutrition tracking:** calories, protein, and fat for every meal, with a breakdown per family member
- **Daily diet goals:** set calorie, protein, and fat targets and see progress bars for today
- **Smart Spin:** one tap fills your whole week, choosing meals that best match your nutrition goals
- **Family view:** see what everyone is eating on any day, plus a full-week table
- **Meal polls:** family members vote on what to make
- **Cloud sync:** data is stored in Supabase and auto-syncs every 15 seconds, with a live sync status indicator

## Built With

- HTML, CSS, and JavaScript (no frameworks)
- Supabase (Postgres database via REST API)
- Netlify (hosting)

## Why I Built It

My family kept going back and forth about what to eat each week, and some of us were tracking nutrition goals. I built this so everyone could plan in one place, see each other's plans, and hit their goals without extra effort.
